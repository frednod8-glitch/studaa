# Ospoly Gist — HTML/CSS/JavaScript blog starter

## Files
- `index.html` — responsive home page, category filters, search, sidebar and ad placeholders
- `article.html` — simple article page with starter article templates selected by URL query
- `style.css` — responsive visual styling
- `script.js` — mobile menu, search, category filtering and demo newsletter response
- `privacy.html`, `disclaimer.html`, `contact.html` — policy/contact starter pages

## Run locally
Open `index.html` in a browser, or open the folder in VS Code and use the Live Server extension.

## Before publishing
1. Replace `https://example.com/` in the canonical link and set up your actual domain.
2. Replace `hello@example.com` in the contact page and site footer with a working email.
3. Replace sample content with original, accurate and dated posts. Verify admission information against official school channels.
4. Add real author details, editorial/about information, working navigation and any required legal disclosures.
5. The newsletter is a front-end demo only; connect it to an email provider or remove it.
6. The ad boxes are placeholders. After approval, insert the ad code provided by Google AdSense and follow Google's current policies. Do not click your own ads or encourage others to click.
7. Set up HTTPS, sitemap.xml, robots.txt, Search Console, analytics if desired, and a consent mechanism if required for your visitors.
8. This is a static frontend; there is no CMS/admin dashboard or database yet. To publish posts without editing files, connect a CMS or build a backend.

## AdSense note
No website can be guaranteed AdSense-approved by its design alone. Approval depends on the live site, content quality/originality, navigation, policy compliance, ownership/domain setup and Google's review. This template provides a useful foundation, not approval.
